# 🖴 Disk Analyzer (Linux GTK3)

Современная, быстрая и нативная утилита для комплексного анализа накопителей на Linux (Linux Mint, Ubuntu, Debian и других дистрибутивах).

Разработана специально с глубокой интеграцией в системную тему **Linux Mint (Mint-Y-Dark)**.

---

## ✨ Возможности

1. **Накопители & S.M.A.R.T.**
   - Автоопределение NVMe, SATA SSD, HDD и USB-накопителей.
   - Быстрый дашборд здоровья (состояние, температура, интерфейс, время наработки).
   - Подробная таблица атрибутов S.M.A.R.T. с контекстным меню расшифровки и режимом мастера (Advanced).

2. **Анализ занятого места**
   - Интерактивный проводник структуры папок.
   - Мгновенный расчёт занятого и свободного места.
   - Быстрый переход и открытие папок в системном файловом менеджере.

3. **Тест скорости (Benchmark)**
   - Проверка последовательного чтения/записи (SEQ 1M) и случайного доступа (4K RND).
   - Спидометр скорости в реальном времени и карточки с результатами.
   - Выбор размера тестового файла (от 64 МБ до 16 ГБ).

4. **Карта блоков & Проверка**
   - **Карта занятого места:** интерактивная Treemap-мозаика файлов и папок (аналог WinDirStat / KDirStat).
   - **Проверка секторов (Блоки):** поблочное сканирование с замером скорости отклика секторов (аналог Victoria / HD Tune).
   - Мгновенное переключение между режимами без задержек.

## 🚀 Установка

### Вариант 1. Установка через `.deb` пакет (Рекомендуется)

Скачайте файл `disk-analyzer_1.0.0_all.deb` из [Releases](../../releases) и установите:
```bash
sudo dpkg -i disk-analyzer_1.0.0_all.deb
```
После этого ярлык приложения появится в меню приложений в категории «Система», а запускать можно командой `disk-analyzer`.

### Вариант 2. Запуск готового бинарника (ZipApp)
```bash
./disk-analyzer.bin
```

### Вариант 3. Запуск из исходного кода
```bash
python3 main.py
```
